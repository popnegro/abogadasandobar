# FASE 02A — FINAL DESIGN INTEGRATION

## Objetivo

Implementar visual y editorialmente las decisiones aprobadas en la Fase 02 y convertir el proyecto en una composición final coherente con sus contenidos y assets reales.

Esta fase es de:

**INTEGRACIÓN + ATERRIZAJE VISUAL**

No es una fase de rediseño libre.

---

# REGLA PRINCIPAL

Integrar contenido real y aprobado antes de ajustar la composición.

---

# 1. IMÁGENES Y ASSETS

Integrar:

- fotografías definitivas;
- imágenes profesionales;
- imágenes de servicios;
- logos;
- favicon;
- Open Graph;
- fondos;
- assets gráficos.

Verificar:

- resolución;
- formato;
- peso;
- relación de aspecto;
- focal point;
- responsive;
- alt;
- lazy loading cuando corresponda.

No inventar imágenes ni sustituir assets sin justificación.

---

# 2. TEXTOS DEFINITIVOS

Integrar únicamente textos reales/aprobados:

- Hero;
- subtítulos;
- servicios;
- especialidades;
- CTAs;
- contacto;
- formularios;
- FAQ si corresponde;
- microcopy aprobado.

No inventar información profesional.

---

# 3. HERO

Ajustar cuando esté justificado:

- altura;
- proporción texto/imagen;
- ancho del contenido;
- tamaño del H1;
- line-height;
- posición de imagen;
- focal point;
- CTA;
- composición Desktop;
- composición Mobile.

No cambiar el contenido para solucionar un problema que pueda resolverse mediante composición, salvo aprobación explícita.

---

# 4. ESCALA VISUAL

Ajustar cuando sea necesario:

- H1;
- H2;
- subtítulos;
- body;
- botones;
- cards;
- imágenes;
- spacing;
- alturas de secciones.

Mantener el sistema visual existente.

---

# 5. DESKTOP Y MOBILE

Validar obligatoriamente.

## Desktop

Revisar:

- navegación;
- Hero;
- imágenes;
- jerarquía;
- cards;
- secciones;
- CTAs.

## Mobile

Revisar:

- Hero;
- orden;
- escala tipográfica;
- imágenes;
- botones;
- spacing;
- navegación;
- lectura.

Nunca aprobar solamente Desktop.

---

# 6. INTEGRACIÓN DEL CONTENIDO

Si el contenido definitivo cambia la composición:

1. ajustar layout;
2. ajustar max-width;
3. ajustar escala;
4. ajustar spacing;
5. ajustar focal point.

No recortar contenido necesario para que encaje.

---

# 7. VALIDACIÓN VISUAL

Comparar:

**ANTES → INTEGRACIÓN → FINAL**

Revisar:

- jerarquía;
- proporciones;
- legibilidad;
- imágenes;
- espacios;
- responsive;
- consistencia.

---

# 8. REGLA DE PRESERVACIÓN

No:

- rediseñar;
- cambiar identidad;
- cambiar navegación;
- eliminar componentes;
- eliminar funcionalidades;
- inventar contenido.
